## Project Overview

CartWise AI is a prototype for analysing retail transaction data and discovering product purchasing patterns using association rule mining.

## Current Progress

### Week 2 – Data Preprocessing and Feature Engineering
- Synthetic retail dataset generation
- Data quality inspection
- Data cleaning and validation
- Feature engineering
- Product basket creation
- Exploratory data analysis
- Data visualizations

### Week 3 – Association Rule Mining
- Apriori frequent itemset mining
- Association rule generation
- Support, confidence, and lift analysis

## Dataset

The current development dataset is synthetic and is used to test the preprocessing and association-rule mining pipeline. It should not be interpreted as real customer purchasing data.
